# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and Semantic Versioning.

## [Unreleased]

## [0.2.0] - 2026-08-25

### Added

- A URL-only Codex workflow with copy-ready Russian and English goal prompts.
- A one-customer-per-workspace contract and a standard local private candidate-profile path.
- Explicit customer-workspace scaffolding and managed Codex skill installation commands.

### Changed

- Agent defaults now require public sources, local preview rendering, and independent approvals for publication, outreach, contact, CRM, and Agent Reach actions.
- Candidate email is optional when a verified HTTPS profile is available; candidate placeholders and incomplete private profiles now block production output.
- Workspace and renderer boundaries now validate canonical paths, immutable profile choice, and intrinsic diagnostics even for direct library callers.
- Customer URL scaffolding accepts internationalized DNS hostnames while preserving ASCII-safe slugs.

## [0.1.0] - 2026-08-25

### Added

- JSON Schema and CLI for target initialization, validation, and rendering.
- Public/private artifact isolation and defensive static-site output.
- Optional, commit-pinned Agent Reach capability-layer health check.
- Portable agent skill, fictional example, tests, packaging smoke test, and multi-platform CI.
